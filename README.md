# ExR

ExR — a cross-platform Android gaming emulator for Windows, Linux, and macOS.

Play mobile games on desktop with high performance, keyboard mapping, multi-instance support, and smooth rendering.

## Goals

- Run Android games on Windows, Linux, and macOS from one codebase
- Low-latency input, keymapping, and gamepad support
- Multi-instance manager for farming / testing
- ADB integration, file sharing, and screen recording
